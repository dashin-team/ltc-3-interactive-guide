## 本地預覽

這是靜態網站，不需建置。在本目錄啟動任何靜態伺服器即可，例如：

```bash
python3 -m http.server 8080
```

然後以瀏覽器開啟 http://localhost:8080

1. 開場三題引導式選擇（照顧方式、你覺得政府能出幾成、錢從哪裡來）並立即回饋數據

3. 長照符合資格：政府長照 3.0 申請檢核、商業長照險巴氏量表六取三互動勾選
4. 長照所需費用：費用分類與 10 年缺口試算器
5. 長照 3.0 政策重點、與 2.0 差異、五大自然缺口
6. 現在規劃 vs 事到臨頭的生活對比
